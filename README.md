# 🌾 مزرعة الهدوء مع الأبطال

لعبة مزرعة وأبطال ومعارك تكتيكية في ملف HTML واحد، تعمل في المتصفح على الهاتف والكمبيوتر.

## التشغيل
افتح `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع ليعمل برابط مباشر.

## المحتويات
- زراعة (17 محصولاً) وحيوانات ومصنع وطلبات وسوق متغيّر
- أبطال ووحوش بعناصر ومعارك تكتيكية (هجوم ذكي / تلقائي / تسريع)
- 100 مهمة وقصة من 12 فصلاً
- لعب مع صديق (تبادل ومحادثة) باتصال مباشر بلا خادم
- حفظ تلقائي على الجهاز، ونسخ احتياطي بملف

> الصور داخل الملف تخص أصحابها؛ استخدمها فقط إن كنت تملك حقوقها.
